# BatteryGuard AI

Prototipo conceptual de una aplicación web para priorizar inspecciones de baterías de vehículos eléctricos. Incluye vistas de flota, detalle de batería y carga de datos. Las cifras y respuestas de IA son ilustrativas; esta entrega es solo frontend y no procesa datos en un servidor.

## Publicación

El sitio está preparado para GitHub Pages. Al subir este repositorio a GitHub en la rama `main`, la acción de GitHub Actions publica `index.html` automáticamente. En el repositorio, la fuente de Pages debe configurarse como **GitHub Actions**.
